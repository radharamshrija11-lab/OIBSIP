# Task 2 – Number Guessing Game

## Internship Domain
Java Development

## Project Description
The Number Guessing Game is a console-based Java application in which the computer generates a random number and the user tries to guess it. The game provides hints such as "Too High!", "Too Low!", and "Correct!" to help the user.

## Features
- Random number generation
- User input using Scanner
- Higher and lower hints
- Attempt counter
- Maximum attempt limit
- Easy, Medium, and Hard difficulty levels
- Play Again option
- Round summaries and score tracking

## Technologies Used
- Java
- Java Random class
- Scanner
- Conditional statements and loops

## How to Run
1. Install the Java Development Kit (JDK).
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the folder containing the Java file.
4. Compile the program:

   `javac NumberGuessingGame.java`

5. Run the program:

   `java NumberGuessingGame`

## Expected Outcome
The user can play multiple rounds, receive hints for each guess, and view the result and round summary.
